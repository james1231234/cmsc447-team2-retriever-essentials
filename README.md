## Retriever Essentials Basic Needs Impact Dashboard

## CMSC 447 Team 2
Retriever Essentials is UMBC's basic needs hub. This project aims to create a secure dashboard that brings together information from different offices and data sources so staff can better understand the impact of basic needs support

## Sprint 1 Goals
Set up the project repository and folder structure
Prepare synthetic data for development and testing
Build the initial dashboard layout
Create basic dashboard metrics and visualizations
Begin project requirements and documentation

## Project Structure
`frontend/`  - dashboard user interface
- `backend/` - server side logic and APIs
- `data/` - synthetic/demo datasets used for development
- `docs/` - project documentation, requirements, and diagrams

## Development Data

The dataset currently used in development is synthetic/demo data.

It contains no real UMBC student information, names, IDs, emails, or actual Retriever Essentials service statistics.

The synthetic data is used only for Sprint 1 development, testing, and dashboard prototyping.
